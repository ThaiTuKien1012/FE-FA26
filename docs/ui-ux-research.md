# UI/UX research

## Access evidence
Mobbin search attempted for grocery ecommerce homepage with featured categories. Service refused: paid plan required (https://mobbin.com/pricing). No screens were returned; no Mobbin application references or findings are claimed. Remaining requested hero, bundle, FBT, cross-sell, add-all, stock and mobile searches were not repeated after the account-level refusal.

Primary supplied reference: https://dribbble.com/shots/27857300-FreshMart-Grocery-Store-Website-Design . Web fetch failed, but a subsequent in-app browser visit successfully opened and visually inspected the exact shot by Orbix Studio LLC. Observed: oversized editorial green hero with grocery/person imagery, rounded pale product cards, category navigation and contrasting promotional blocks. The page confirms all eight supplied palette colors. Adapt the hierarchy, grocery imagery and clear scanning; do not copy its assets or unsupported delivery/offer claims. The implementation uses an original split grocery-basket hero and existing local assets.

## Design decisions pending reference validation
- Grocery discovery: visible store context, search, category filters and current price.
- Banner: one clear action to its configured group; neutral catalog action when no active banner exists.
- Bundles: constituent products before total; explicit quantities; one atomic add-all action.
- FBT: checkbox selection updates total; unavailable products disabled.
- Cross-sell: separate section with individual quick-add and product detail actions.
- Mobile: stacked hero/dialog content, readable prices, large controls, no horizontal page overflow.

These are engineering/design judgments grounded in the brief, not Mobbin findings. Taste Skill informs spacing, typography, a single color/button system, honest copy and restrained motion. Its generic marketing template/dealt palette/full-screen-section rules are superseded by this grocery brief's explicit art direction and existing application architecture.
